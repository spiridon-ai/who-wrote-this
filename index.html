Who wrote this?

Students posted on a Padlet board without logging in. Drop in the board's export and paste your class list to see which student wrote each post.

Everything stays in your browser. The file and the class list are never uploaded; this page makes no network requests after it has loaded.

An independent tool. Not made by or affiliated with Padlet.
